# Kumari Trails

A responsive React + Vite + TypeScript tourism website starter for Kanyakumari.

## Requirements
- Node.js LTS
- VS Code (recommended)

## Setup
1. Extract this ZIP file.
2. Open the `kumari-trails` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```bash
npm install
npm run dev
```

If PowerShell blocks the `npm` command, use:

```powershell
npm.cmd install
npm.cmd run dev
```

5. Open the local URL shown in the terminal, usually http://localhost:5173.

## Production build
```bash
npm run build
```

## Notes
- Destination images are illustrative stock images, not verified photographs of the named attractions.
- Business links open external websites or Google Maps searches. They do not provide live booking or availability confirmation.
- Verify business details, access conditions, opening hours and travel safety before publishing.


## Photo credits and accuracy
Some destination cards now use photographs published on the Kanniyakumari District Administration tourism page (Kalikesam, Padmanabhapuram Palace, Chittar Dam, Thirparappu Falls, and Kodayar Twin Falls). The Chitharal Jain Temple card uses a Wikimedia Commons photograph by Athulvis under CC BY-SA 4.0; credit and license details: https://commons.wikimedia.org/wiki/File:Chitharal_Jain_Temple_or_Chitharal_Malai_Kovil_(20946).jpg . These image URLs require an internet connection. Other destination cards still use temporary illustrative images until verified photographs are available.


## Destination photographs
User-supplied photographs are stored locally in `public/images/` and used by the destination cards and detail pages. Images currently supplied: Thiruvalluvar Statue, Vali Chunai, Lemur Beach, Velimalai Hills, Marunthuvazh Malai, Mathur Aqueduct, Olakaruvi Waterfalls, Sanguthurai Beach, Kodayar Twin Falls, Upper Kodayar, and Karumparai Falls. Other destinations retain their existing image until a matching photo is supplied.
